# 2022 mitochondrial calcium precursor model

This directory preserves an exploratory Birmingham-era mitochondrial Ca²⁺ model that was previously stored in the mixed public repository `esig626/Dynamical_systems`.

It is retained here because it belongs to the same broader cell-metabolism and mitochondrial-modelling period that preceded the later SDH/chromaffin work. Its placement is archival. It should not be interpreted as evidence that this component was part of the final SDHB model or publication.

The model is a closed-cell system with cytosolic, endoplasmic-reticulum, mitochondrial, and microdomain compartments. It includes IP3 receptor fluxes, SERCA, mitochondrial Ca²⁺ uptake through MCU, mitochondrial Na⁺/Ca²⁺ exchange, mPTP fluxes, buffering, and inter-compartment leaks.

Files

- `Parameters_ca2.m`
- `ca2.m`
- `ca2_ex.m`

The broader 2022 kinetic metabolism file that was also present in `Dynamical_systems` remains preserved byte-for-byte in that legacy repository rather than being rewritten during consolidation.

The original source was `esig626/Dynamical_systems`, commit `d95cacfad8890a35e9a533e0e847921b128f8693`. The three MATLAB files transferred here retain their original Git blob hashes.
